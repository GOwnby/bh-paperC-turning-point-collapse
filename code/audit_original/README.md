# Archived original audit scripts and logs (Paper C)

These are the scripts and logs of the author's earlier audit sessions, copied unchanged from the author's archive
(`archive_paperC_combined/audit/{audit_eos,audit_text}` and `archive_paperC_combined/audit2/{audit_fold,audit_lag,audit_text2}`;
page images and PDF renders of the manuscript are left out). They are the origin of several numbers quoted in the paper and in the
technical report (see `PROVENANCE.md`, section "Files without an original").

They are **archived evidence, not part of `verify.sh`**: they contain absolute paths of the author's earlier sessions
(`/tmp/claude-0/.../scratchpad/...`, `/mnt/user-data/outputs/...`) and import modules that were then in those directories. Their results are
regenerated by the executable scripts of this repository (for example `lag_eigs.py`, `lag_checks.py`, `fold_trapped_diag.py`, `pi_checks.py`,
`fold_numbers.py`, `eos_numbers.py`, `misc_checks.py`, `turning_point_table.py`), whose outputs `verify.py` compares with the paper.

| directory | content | regenerated by |
|---|---|---|
| `audit_eos/` | EOS / TOV / Newtonian-limit / force / trajectory audits (`t1_eos.py` ... `t15_eig.py`, `exactV.py`) | `eos_numbers.py`, `misc_checks.py` |
| `audit_text/` | numbers quoted in the text (`t1.py` ... `t8.py`, `figs_nl.py`, `d_r.npy`, `t4.out`) | `misc_checks.py`, `turning_point_table.py` |
| `audit_fold/` | fold-passage and damping audits (`chk*.py`, `damp*.py`, `osc.py`, `pi_chk*.py`, `step2.py`, `sym.py`, `univ.py`, `nums.py`) | `pi_checks.py`, `fold_numbers.py`, `symbolic/` |
| `audit_lag/` | Lagrangian integrations to the apparent horizon (`evolve.py`, `ab.py`, `ahpar.py`, `cflscan.py`, ..., logs and `ev_*.json`) | `lag_eigs.py`, `lag_checks.py`, `fold_trapped_diag.py`, `rr_at.py` |
| `audit_text2/` | black-hole formation and damping checks (`bh_check*.py`, `pi_check*.py`, `damp_check.py`, logs) | `fold_trapped_diag.py`, `pi_checks.py` |

This directory is unrelated to the Lagrangian study of the technical report, which is in `technical_report_phase2/ancillary/lagrangian_L/`.
